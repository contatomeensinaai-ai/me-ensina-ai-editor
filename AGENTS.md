# Me Ensina AI Editor

Para instalar ou abrir, leia `plugins/me-ensina-ai-editor/skills/editor-local/SKILL.md`. O usuário não deve precisar procurar executáveis ou digitar comandos no Terminal. Use os mecanismos de plugin/marketplace oferecidos pelo Codex atual, confirmando o resultado. Nunca declare instalado só porque copiou os arquivos.

Esta é uma versão piloto para Mac Apple Silicon. Não encerre nem recarregue uma edição aberta. O launcher aceita `--no-open` para que a URL seja aberta no navegador interno pelo Codex. Não use o antigo Instalar.command 0.1.0.

Credenciais não fazem parte do projeto. Não publique vídeos, projetos privados ou diagnósticos com dados pessoais. Modelos de IA exigem autorização separada de download. A preparação só baixa bibliotecas de versões fixadas e verifica integridade.
