# Validação do piloto 0.1.1

- Manifesto do plugin e skill aprovados nos validadores oficiais.
- Quinze testes passaram com Node embarcado v22.23.2: servidor HTTP, Range, rejeição de caminhos/origens indevidos, sessões, gravação SRT, CLI opcional, preservação de serviço existente, preparação única e configuração de release.
- Preparação real em diretório isolado: 12 bibliotecas verificadas por SHA; npm ci com scripts desativados; Vite compilou o editor.
- Lockfile normalizado para registry.npmjs.org; instalação repetida com cache novo: 324 pacotes instalados com integridade preservada.
- Interface abriu no navegador em porta isolada; seleção Português/English/Español e barra com filtros/máscara visíveis.
- ZIP público de preparação: 42.827.468 bytes, SHA-256 d6a616109b8b16a0827494c07d5b9d278f2224f747ff050dac7ba0614cfdb180. Não contém modelos, vídeos privados nem binários FFmpeg/libav.
